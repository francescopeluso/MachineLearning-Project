\section{U-Net Architecture}
\label{sec:unet}

U-Net is a Convolutional Neural Network architecture originally designed
for image segmentation. Unlike a standard CNN used for classification,
which produces a single prediction for the entire input image, U-Net
produces a prediction for each pixel. Therefore, given an input image of
size $H \times W$, the network produces a segmentation map with the same
spatial dimensions.

The architecture follows an \textbf{encoder--decoder} structure and has
a characteristic symmetric shape, from which the name U-Net derives.
It can be divided into three main components: the encoder, the bottleneck,
and the decoder.

\subsection{Encoder}

The \textbf{encoder} is the first part of the network and works similarly
to a traditional CNN. Its purpose is to progressively extract more
complex features from the input image.

Each encoder stage applies convolutional operations followed by
non-linear activation functions. Downsampling operations progressively
reduce the spatial resolution of the feature maps while increasing their
number of channels.

A simplified example is:

\begin{equation}
H \times W \times C
\rightarrow
\frac{H}{2} \times \frac{W}{2} \times 2C
\rightarrow
\frac{H}{4} \times \frac{W}{4} \times 4C
\rightarrow \dots
\end{equation}

As the image passes through the encoder, the network therefore moves
from high-resolution spatial information to more abstract features.
This allows the network to recognize structures and patterns that are
useful for distinguishing solar filaments from the surrounding solar
surface.

However, this process also causes a progressive loss of spatial
information. This is not a major problem for image classification, where
only the presence of an object or class is required, but it becomes
important for segmentation, where the exact position of each detected
structure must be recovered.

\subsection{Bottleneck}

The \textbf{bottleneck} represents the deepest part of U-Net and connects
the encoder with the decoder. At this stage, the feature maps have the
lowest spatial resolution but contain the highest-level representation
extracted by the network.

Its role is to provide the decoder with a compact representation of the
input image containing the information needed to determine which
structures are likely to correspond to solar filaments.

\subsection{Decoder}

The \textbf{decoder} performs the opposite spatial transformation with
respect to the encoder. Starting from the low-resolution representation
produced by the bottleneck, it progressively increases the spatial
resolution of the feature maps.

This process can be represented as:

\begin{equation}
\frac{H}{2^n} \times \frac{W}{2^n}
\rightarrow \dots \rightarrow
\frac{H}{2} \times \frac{W}{2}
\rightarrow
H \times W.
\end{equation}

The purpose of the decoder is therefore to transform the features
extracted by the encoder into a pixel-wise segmentation map. A final
convolutional layer produces one output value for each pixel. In the
binary segmentation case, these values can be converted into filament
probabilities using a sigmoid activation function.

\subsection{Skip Connections}

A simple encoder--decoder architecture would still suffer from the
spatial information lost during downsampling. U-Net addresses this
problem through \textbf{skip connections} between corresponding stages
of the encoder and decoder.

Instead of forcing all information to pass through the bottleneck,
feature maps produced by the encoder are directly transferred to the
decoder at the corresponding resolution. These features are typically
concatenated with the decoder features before applying the following
convolutional operations.

The overall information flow can therefore be summarized as:

\begin{center}
\texttt{Input $\rightarrow$ Encoder $\rightarrow$ Bottleneck
$\rightarrow$ Decoder $\rightarrow$ Segmentation Mask}
\end{center}

with additional skip connections:

\begin{center}
\texttt{Encoder features $\longrightarrow$ Decoder features}.
\end{center}

This mechanism allows the decoder to combine two different types of
information:

\begin{itemize}
    \item \textbf{high-level features}, produced by the deeper layers,
    which help determine whether a structure represents a filament;
    \item \textbf{fine spatial features}, obtained from the earlier
    encoder layers, which help reconstruct its position, shape and
    boundaries.
\end{itemize}

This characteristic is particularly relevant for our dataset. Solar
filaments can be thin, elongated and irregular structures, and excessive
loss of spatial information during downsampling could cause them to be
incorrectly reconstructed or fragmented.

\subsection{U-Net for Binary Segmentation}

For the considered task, U-Net is configured to produce a single output
channel. For every pixel $(i,j)$, the network produces a logit
$z_{ij}$, which can be converted into a probability through the sigmoid
function:

\begin{equation}
p_{ij} = \sigma(z_{ij})
       = \frac{1}{1 + e^{-z_{ij}}}.
\end{equation}

The resulting probability map has the same spatial dimensions as the
input segmentation mask. A threshold $t$ can then be applied to obtain
the final binary prediction:

\begin{equation}
\hat{y}_{ij} =
\begin{cases}
1, & p_{ij} \geq t, \\
0, & p_{ij} < t.
\end{cases}
\end{equation}

Therefore, the complete process can be summarized as:

\begin{equation}
\text{Solar Image}
\rightarrow
\text{U-Net}
\rightarrow
\text{Probability Map}
\rightarrow
\text{Binary Filament Mask}.
\end{equation}
