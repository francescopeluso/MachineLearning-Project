\section{Introduction}
\label{sec:introduction}

The objective of this project is to identify solar filaments in solar images using Machine Learning. The problem is formulated as a \textbf{binary semantic segmentation task}: given a solar image, the model must produce a binary mask in which each pixel is classified as either \textit{filament} or \textit{background}.

The analysis of the training images highlights some relevant challenges. Solar filaments usually appear as dark, thin and irregular structures over the solar disk. Their contrast with the surrounding regions can be low and their shape and size can vary considerably between different images. Moreover, the solar surface contains other structures and background noise that may have visual characteristics similar to those of a filament.

Another important aspect is the strong imbalance between the two classes. Filaments generally occupy only a small portion of the complete image, while most pixels belong to the background. For this reason, correctly identifying the filament regions is more relevant than simply maximizing pixel-wise classification accuracy.

The project therefore focuses on models capable of combining the extraction of high-level features with the preservation of fine spatial information. The quality of the resulting segmentation is evaluated mainly through the \textbf{Dice coefficient}, which measures the overlap between the predicted binary mask and the corresponding ground-truth mask.

\section{Proposed Approach}
\label{sec:approach}

\subsection{Network Architecture}

The main approach considered for this project is based on a
\textbf{U-Net convolutional neural network}, an architecture specifically
designed for image segmentation.

The CNN architectures studied for image classification are not directly
suitable for our problem. A classification network progressively extracts
features from an image and finally produces a prediction for the whole
input, such as a class label. In semantic segmentation, instead, the
position of the detected features is also important, since the network
must assign a class to each pixel of the image.

U-Net addresses this problem using two main paths. The first progressively
extracts higher-level features and reduces their spatial resolution,
similarly to a standard CNN. The second progressively increases the
resolution of these features until a segmentation mask is obtained.

An important characteristic of U-Net is the use of \textbf{skip
connections} between different parts of the network. These connections
allow features containing fine spatial information to be reused when
constructing the output mask. This is particularly useful in our problem,
since solar filaments can be thin, irregular, and difficult to distinguish
from the surrounding solar surface.

\subsection{Advantages and Limitations}

The main advantages of this approach are:

\begin{itemize}
    \item U-Net is specifically designed for pixel-wise image segmentation;
    \item it is based mainly on convolutional operations, which are already
          suitable for extracting spatial features from images;
    \item skip connections help preserve information about small and thin
          structures;
    \item the architecture is relatively simple and can be modified to
          experimentally evaluate different configurations.
\end{itemize}

Some limitations must also be considered:

\begin{itemize}
    \item reducing the spatial resolution may cause information about very
          thin filaments to be lost;
    \item processing high-resolution images requires more GPU memory;
    \item the strong imbalance between filament and background pixels can
          make the training more difficult;
    \item structures with an appearance similar to filaments may generate
          false positive predictions.
\end{itemize}

\subsection{Alternative Approaches}

As an alternative, a \textbf{Residual U-Net} could be considered by
introducing residual blocks and skip connections inside the network.
This would allow us to investigate the residual learning techniques
studied during the course in the context of image segmentation.

Another possibility is to use a \textbf{pre-trained CNN} as part of the
U-Net architecture and apply transfer learning and fine-tuning. This
could be useful especially if the available training set is not large
enough to learn robust visual features entirely from scratch.

More advanced segmentation architectures could also be considered.
However, U-Net represents a suitable starting point because of its
relatively simple architecture and its direct use of convolutional
layers and skip connections.
